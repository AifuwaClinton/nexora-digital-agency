Nexora Digital Agency

Nexora is a responsive digital agency website built to showcase digital services, projects, and team members.

Live Demo

https://nexora-digital-agency-nine.vercel.app

Technologies Used
	•	React
	•	JavaScript
	•	Tailwind CSS
	•	Vite

Features
	•	Responsive design for mobile and desktop screens
	•	Services and project sections
	•	Team profiles
	•	Contact section
	•	Light and dark mode toggle

What I Learned
	•	Building user interfaces with React components
	•	Managing component state with React’s useState
	•	Creating responsive layouts with Tailwind CSS
	•	Adding interactive features such as a theme toggle

Getting Started

To run this project locally:
	1.	Clone this repository.
	2.	Open the project folder in your terminal.
	3.	Install the dependencies using npm install.
	4.	Start the development server using npm run dev.
	5.	Open the local address shown in your terminal.
